验收范围：订单、开单、生产流转、成本、管理员权限、电脑端与手机端  

## 1. 验收结论

技术验收结论：**有条件通过，可以切换新版 UI。**

切换条件：

1. 新业务数据统一从新版 UI 录入。
2. 旧版 UI 暂时保留为只读查询入口，不再录入新数据。
3. 旧版报价单 Word/Excel/PDF 占位导出不纳入本次切换承诺；需要使用时另立验收项。
4. 正式停用旧版前，由业务负责人完成第 7 节人工签字。

## 6. 切换与回退方案

1. 切换日开始，新单只允许在新版创建。
2. 旧版保留只读查询，不允许继续形成双写数据。
3. 首周每日检查登录失败、HTTP 500、慢接口和邮件失败。
4. 出现阻断性问题时，保留数据库不回滚；临时恢复旧版操作入口，并登记问题单。
5. 连续稳定运行一个观察周期后，再决定关闭旧版入口。
