# 内容发布台操作手册

更新时间：2026-08-10

## 每日流程

1. 登录 `https://cahs.top/new/`，进入“内容发布台”。
2. 核对平台、标题、正文、来源链接、图片和建议时间。
3. 点击“生成平台配图”，下载系统生成的对应尺寸图片。
4. 复制标题与正文，点击“打开平台”。
5. 在官方平台完成最后预览。不得跳过账号归属、图片、链接和技术表述检查。
6. 人工发布后复制公开 URL，回到工作台点击“完成”。
7. 发布 7 天或 28 天后，把平台公开的曝光、点击和互动数据录入绩效快照。

发布动作不会由工作台自动执行。任何验证码、二次验证、平台审核或账号限制均应在官方平台处理。

## Pinterest

- 适合：产品实拍、结构对比、材料选型表、采购清单。
- 使用竖版 `1000×1500` 图片；主体应完整，不能裁掉袋口、底封或卷芯。
- 标题围绕单一采购问题，描述补充材料、袋型、应用和官网来源。
- 选择与主题最接近的 Board，不要把全部内容放进同一个泛化 Board。
- 发布后记录 Pin 的公开 URL；7/28 天回填 impressions、outbound clicks 和 saves。
- 避免：重复上传同图同文、没有说明的纯产品图、未经验证的性能数字。

## LinkedIn

- 适合：工厂证据、技术判断、法规背景、项目交接、采购决策。
- 使用 `1200×627` 横图；正文采用“问题 → 判断条件 → 证据 → 保守结论 → 来源”。
- 第一段直接说明买家会遇到的决策，不使用空泛宣传口号。
- 公司页发布需要操作者具备对应 Page 权限；工作台不会绕过平台权限。
- 发布后记录公开 post URL；7/28 天回填 impressions、clicks、reactions、comments 和 reposts。
- 避免：同一天连续发布多条相似链接、虚构客户、把样品测试写成普遍保证。

## 知乎

- 适合：材料结构解释、袋型比较、设备兼容、测试和采购误区。
- 标题应是用户真实问题，正文先给结论，再解释条件和验证方法。
- 使用 `1200×675` 横图；表格和结构图必须能在手机端阅读。
- 原文链接放在确有引用价值的位置，避免正文只有摘要和跳转链接。
- 发布后记录回答或文章 URL；回填阅读、赞同、收藏和评论。
- 避免：机械翻译英文博客、堆关键词、批量发布高度相似答案。

## 内容与图片审核

- 品牌统一为“Huasheng Packaging / 华胜包装”。
- 不写 `BRC certified`、`No.1`、`best supplier`。
- 不把建议材料写成唯一方案，不虚构 OTR、WVTR、温度、压力或保质期数据。
- 产品图片必须与袋型相符；四边封、八边封、自立袋和卷膜不得混用结构。
- 实拍图可做清洁、校色、构图和背景优化，但不得改变真实印刷结构与包装特征。
- 每条稿件至少保留一个可核验的官网来源链接。

## 发布节奏

- 每天最多安排一条中文、一条英文，两个时段分开。
- 同一平台默认不连续两天发布同类主题。
- 内容比例：采购判断 35%、真实证据 30%、应用 20%、法规与测试 15%。
- 先执行 30 天，再按曝光、点击、收藏和引荐访问调整，不凭主观提高频率。

## 异常处理

- 平台打不开：标记“稍后处理”，不要反复登录触发风控。
- 图片不合适：不要发布，反馈来源页面与问题类型。
- 文案存在技术疑问：暂停该任务，交由管理员核对。
- 发布错误：在平台侧修正或删除，并在工作台保留说明，不伪造公开 URL。
