## Baseline Limitations

Public search results and Search Console are sampled views; absence is not proof that no link exists.

- Search result coverage, ranking, snippets, and cache age vary by engine, locale, and time.
- Search Console data was not supplied, so this baseline cannot reconcile indexed mentions with owner-only link data.
- A discoverable mention is not automatically a live backlink. A referring root domain is counted only after its public source page and clickable destination can be verified.
- Public search snippets can preserve older footer or page text. They are sufficient to raise a conflict gate, but not to approve any disputed fact.
